- (decision) Paradigm: hexagonal (ports & adapters) with a functional core. domain = pure calculations + port interfaces; new packages/app = use cases (the only write path); db/importers/connectors/llm = adapters; apps/server = composition root. Binds all epics. Prevents: each entry point (HTTP, jobs, CLI, import commit) inventing its own write path and bypassing audit/redaction. - (decision) Single write path: HTTP routes, job handlers, import commit and the pangolin CLI all call packages/app use cases; nothing else opens a write transaction or writes audit_log. Prevents: job runner or CLI writing via repositories directly. User agreed.
- (decision) No await inside a write transaction (better-sqlite3 is synchronous): outbound/slow I/O (LLM, price fetch, PDF text extraction, file reads) completes first; the use case then opens one short synchronous transaction to validate, write and audit. Prevents: long-held write locks and async-in-transaction bugs across epics. Proposed with option A; user accepted.
- (decision) Visibility is one dimension (viewer), no household/mine lens: every view, including household totals and net worth, covers the viewer's visible accounts = shared + public + the viewer's own private accounts. So the two partners can see different household figures. Overrides spec wording (data-model.md Privacy enforcement; CAP-17 'excluded from shared views') -- offer to update the spec at close. User's call.
- (decision) Privacy contract (a): every use case takes a Viewer; visibleAccounts(viewer) is a SQL fragment composed into every query touching account/transaction/split (sums, FTS5 search, exports), never an in-memory post-filter; redact(viewer, rows) runs once at the app boundary on the way out (API, exports, audit-log reads); domain never queries. Hidden names expire at read time (name_hidden_until > today), no job. Prevents: report epics computing totals with a post-filter, or search/export leaking hidden names.
- (decision) SystemViewer sees everything; only the job runner and CLI composition roots can construct it; no HTTP route can run as system. Cloud-LLM field minimisation (no private txns, names, people) is a rule of the LLM purpose, applied independently of visibility. User agreed.
- (decision) A private account (or anything under it) addressed by a non-owner returns NotFound, never Forbidden, for reads and writes alike. User's call.
- (decision) Hidden transaction names stay hidden from the partner everywhere, including in the partner's own audit-trail entries for edits they made (shows 'Hidden until <date>'). User's call.
- (decision) Splits in a private account cannot carry beneficiary=shared (forced to the account owner). Shared budgets, contribution apportionment and any shared figure are identical for both partners and contain no private amounts. Binds epics 2, 4, 6, 7. - (decision) Period contract (d): Temporal PlainDate everywhere; domain never reads the system clock, uses an injected Clock in household timezone; periods half-open [start,end) internally, inclusive for display; a split belongs to the period of its transaction's posted_on; FY labelled by ending year (FY2025 = 2024-07-01..2025-06-30); monthly anchor = day-of-month, clamped to month end. - (decision) Pay-period alignment is a per-anchor setting: 'calendar' (pure rule from cadence+anchor) or 'deposit' (boundaries follow actual detected pay deposits). User: make it an option for either.
